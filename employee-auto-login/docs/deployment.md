# Deployment Instructions for Employee Auto-Login System

## Prerequisites
Before deploying the Employee Auto-Login system, ensure that the following prerequisites are met:
- Windows operating system (Windows 10 or later recommended)
- PowerShell version 5.1 or later
- Administrative privileges to create scheduled tasks

## Deployment Steps

1. **Clone the Repository**
   Clone the repository containing the Employee Auto-Login system to your local machine:
   ```
   git clone <repository-url>
   cd employee-auto-login
   ```

2. **Configure Company Settings**
   Modify the `config/company.example.json` file to include your company's specific settings. Ensure that you provide the necessary API endpoints and credential storage options.

3. **Install Required Modules**
   The system relies on several PowerShell modules. Ensure that the following modules are available:
   - CompanyConfiguration
   - CredentialStore
   - AuditLogging

   You can import these modules in PowerShell using:
   ```powershell
   Import-Module .\src\modules\CompanyConfiguration.psm1
   Import-Module .\src\modules\CredentialStore.psm1
   Import-Module .\src\modules\AuditLogging.psm1
   ```

4. **Register the Login Task**
   Run the `Register-LoginTask.ps1` script to create a scheduled task that automates the login process for employees:
   ```powershell
   .\src\Register-LoginTask.ps1
   ```

5. **Verify Scheduled Task**
   After registration, verify that the scheduled task has been created successfully. You can check this in the Task Scheduler under the "Task Scheduler Library".

6. **Testing the Setup**
   It is recommended to test the auto-login functionality to ensure everything is working as expected. You can run the `Invoke-EmployeeLogin.ps1` script to simulate a login:
   ```powershell
   .\src\Invoke-EmployeeLogin.ps1
   ```

7. **Unregistering the Task**
   If you need to remove the scheduled task at any point, you can run the `Unregister-LoginTask.ps1` script:
   ```powershell
   .\src\Unregister-LoginTask.ps1
   ```

## Additional Notes
- Ensure that all employees who will use the auto-login feature have their credentials securely stored using the CredentialStore module.
- Regularly review the audit logs generated by the AuditLogging module to monitor login attempts and ensure security compliance.

By following these steps, you can successfully deploy the Employee Auto-Login system in your company environment.
